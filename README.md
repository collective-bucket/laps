# LAPS!

Fethiye’de bir büfe. Şimdilik yalnızca yakında sayfası.

Yayın: [collective-bucket](https://github.com/collective-bucket) Firebase Hosting
(`cbucket-laps` → `laps.collectivebucket.com`). Alan adı `lapsfethiye.com`
Squarespace üzerinde; DNS bağlanınca aynı site oradan da açılır.

Kelime işareti bu lisansın kapsamında değildir.

## Yerel

```bash
npm install
npm run serve
```
